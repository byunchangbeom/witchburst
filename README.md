# 마녀포격단 · Witchburst

꼬마 마녀와 정령이 저주를 정화하는 모바일 우선 방치형 RPG의 첫 플레이다. 방향 정본은 [GAME-BRIEF.md](GAME-BRIEF.md)다. 출시 패키지는 아직 없다.

## 실행과 첫 플레이

Godot 4.7.2와 Python 3을 사용한다. 저장소 루트에서 실행한다.

```sh
godot --path game
godot --editor --path game
```

시작 즉시 자동 이동·사격한다. 적 정화로 별빛과 정화잎을 얻고, 하단의 공격력·사격 속도·획득량을 강화한다. 전투 영역 드래그는 선택 조작이며 손을 놓으면 자동 이동으로 돌아간다. 적 12마리 뒤 가시왕이 등장한다. 제한시간 24초, 보스용 별비는 8초 쿨다운이다. 실패 시 재화·장비·강화를 유지하고 다시 도전한다.

‘장비·정령’에서 별빛 12로 뽑기, 잎 3으로 새싹 마도구 제작, 같은 등급 2개를 상위 1개로 합성한다. 상위 장비 획득은 자동 장착되며 등급별 수동 장착도 가능하다. 3등급의 공격 배율은 1.3/2.1/3.4다. 정화잎 4로 정령을 해금하면 매 세 번째 사격에 65% 위력 연계탄이 추가된다. 메뉴를 열면 전투가 일시정지한다. 닫고 전투로 돌아간다.

보스를 이긴 뒤 환생할 수 있다. 환생은 별빛·잎·강화·마도구·미수령 보상을 초기화하고 정령·로컬 소유자·환생 횟수를 보존한다. 환생당 영구 마법 위력 +25%를 받는다. 승리 후 환생 없이 반복 전투도 가능하다. 이 수치·가격·확률은 첫 플레이 조정용 가설이다. 뽑기 확률은 새싹 80%/달빛포 18%/성운포 2%다. 광고·실제 결제는 없다.

## 저장과 재접속

로그인 없이 `user://progress.json`에 기기별 진행을 저장한다. 5초 주기, 성장 행동, 정상 창 닫기 시 저장한다. macOS 기본 경로는 `~/Library/Application Support/witchburst/progress.json`이다. 장비·정령 메뉴에서 재접속 보상을 한 번 수령한다. 누적 상한은 24시간이며 분당 별빛 `2 + 환생 수`를 사용하는 임시 계산이다. 1분 미만 구간은 버림 처리한다.

재접속 시 기준 시간을 먼저 디스크에 확정하고, 수령 시 미수령액과 재화를 함께 저장한다. 저장 실패 시 성장·수령을 되돌린다. 잘못된 JSON은 원본을 보존하고 최신 백업을 복구하며, 백업 복구 시 오프라인 보상은 중복 방지를 위해 생략한다. 기기 내 파일이므로 임의 파일 복원·변조를 서버에서 판별하는 기능은 없다.

후속 **IdP 로그인·기기 간 진행 공유·기존 로컬 진행 이전은 필수 요구**이며 현재는 미구현이다. 버전·소유권·복구와 후속 동기화 정책은 [현재 설계](docs/design.md)에 기록한다.

## 검사와 확인 범위

```sh
python3 tests/run.py
python3 tests/run.py --capture --artifacts /tmp/witchburst-review
```

`tests/run.py`는 기본 씬과 제품 함수를 사용해 전투·강화·뽑기·제작·합성·정령·환생·저장·입력 경로와 신규 표현 계층을 검사한다. 임시 프로젝트·테스트 전용 진행 파일·고유 엔진 사용자 경로를 사용하며 설치 엔진·HOME·CODEX_HOME을 바꾸지 않는다. 임포트 종료 코드가 0이어도 오류 로그가 있으면 실패하고 이후 검사를 실행하지 않는다.

이번 포신·지형 수정 후 `python3 tests/run.py --artifacts /tmp/witchburst-axis-terrain-current`는 사용자 저장 디렉터리 생성·인증서 접근·에디터 설정 저장 권한 오류로 **임포트 실패**했다. 엔진 종료 코드 0이어도 로그 오류를 검출해 실행기는 1을 반환했다. smoke·캡처는 실행하지 않았으며 로그를 해당 폴더에 보존했다. sandbox에서 GUI·엔진 복제·환경 우회를 반복하지 않았다. Python 호스트 캡처 계약 검사 **8개 통과**는 합성 PNG 헤더/좌표 fixture의 거부 계약이며 실제 렌더링 증거가 아니다.

등록된 Controller 검사는 커밋 고정 뒤 `tests/run.py` → 호스트 `render_check.py` 순서다. 캡처는 기존 11상태에 초기/성장 비행·보스 발사/비행을 추가한 **15상태×3비율=45 PNG**다. 크기는 540×960 / 540×1200 / 720×960이다. `10-first-shot`·`11-grown-shot`·`14-boss-shot`과 `12-first-flight`·`13-grown-flight`·`15-boss-flight`를 비교한다. 발사/비행 fixture는 실제 `_fire()` 호출 후 반동·호흡1을 고정하며 비행은 규칙 탄을 표적 쪽으로80단위 옮겨 표현을 확인한다. 자연 전투·입력/저장 회귀와 구분한다.

각 기록에는 원본 포구/포신 픽셀의 실제 Sprite2D 변환, 초기8단위 탄 방향, 탄 머리/꼬리·발사 입자, 배경 원본 좌표로 환산한 발밑 그림자를 남긴다. 호스트는 포구만 맞고 초기 탄도가 어긋난 경우, 절벽 배치, 필수 비행 화면 누락을 거부한다. `--capture`는 실제 디스플레이가 있는 호스트에서만 사용한다. 독립 리뷰어는 정확한 커밋에 연결된 `check-1/render-captures` PNG와 레퍼런스를 직접 비교해야 한다. 실제 텍스처 로드·셰이더 GPU 컴파일·렌더링 검증은 호스트 실행 대기다.

## 그림책 시각 교체와 수용 상태

사용자가 반려한 도형 캐릭터·어두운 통로·기존 버튼을 신규 표현으로 교체했다. 제공된 **imagegen PNG 4장**을 원본 보존 복사해 시작 마녀/큰 마법포·씨앗/가시왕/여우정령·밝은 사선 풀밭에 실제 적용한다. 생물은 AtlasTexture로 분리하고 배경은 종횡비를 유지해 화면을 채운다. 작은 HUD·측면 기능 아이콘·갈색 테두리와 그림자를 가진 민트/크림 강화 3카드, 종이색 공방·환생 안내를 사용한다.

별도 `storybook.gd` 표현 계층의 Tween 호흡·반동·피격, 실제 연결된 CanvasItem ShaderMaterial 2종(피격 흰색 섬광·국소 마법/정령 맥동), CPUParticles2D 발사·적중·정화/보상 효과가 전투를 보완한다. 입자는 최대12슬롯×18개이며 만료 슬롯을 재사용한다. 전투 그림과 입자는 HUD·메뉴 뒤에서 그린다. 상세 비교와 반려 해결 상태는 [아트 방향](docs/art-direction.md)에 있다.

반동·호흡이 적용된 마녀 Sprite2D의 실제 포구와 원본 포신 축을 함께 읽는다. 처음28단위는 그 축으로 전진하고 이후 풀밭의 표적으로 휘어지는 마법 궤적이다. 꼬리도 같은 경로의 앞선 지점으로 연결하며 출발 시 길이0, 성장별 길이 상한을 지킨다. 적·그림자·체력바·피해 숫자·적중/보상 입자에는 배경의 확대·잘림과 연결한 공통 풀밭 좌표 보정을 적용한다. 드래그 영역에서는 보정이0이다. 전투·충돌·피해·비행시간·합성·뽑기·환생·저장 자료는 기존 시뮬레이션을 보존한다. 표현 자료와 입자 슬롯은 회수·재사용한다.

**시각 교체 구현은 사용자 디자인 재수용을 뜻하지 않는다. 기존 반려는 유지하며 최종 수용은 NOT_MEASURED다.** 실제 렌더러·독립 아트 리뷰·이번 소스의 OS 입력·음향 청취·사람 재미·모바일 실기기와 Android/iOS/Windows/웹 내보내기는 미검증이다. 자동 검사와 캡처 생성만으로 시각 품질이나 재미를 PASS로 판정하지 않는다.

자산 출처는 [asset-sources.json](docs/asset-sources.json)에 있다. 독립 리뷰·통합·push·정리 상태의 정본은 Harness V runtime이다.
