# 첫 전투 설계 · 조정용 가설

정본은 루트 GAME-BRIEF.md다. 이번 작업은 저장·합성·환생 앞 단계의 첫 지역/보스 전투다. 아래 수치는 첫 플레이 조정을 위한 임시값이며 참고 게임에서 측정하거나 복사한 값이 아니다.

## 체험 가설

처음에는 작은 마녀의 별 지팡이에서 단발 마법이 나가고 저주 정령이 여러 번 맞아야 정화된다. 별빛으로 공격을 올리면 지팡이→마법포→거대 마도구로 외형과 탄 크기가 커지고, 동행 정령 수·발사 불꽃·명중 파편이 늘어난다. 반동·부유 동작·피해 숫자·파괴 파편·재화 숫자·효과음의 연결로 ‘내가 키운 화력’이 읽힌다는 가설이다. 현재 정령 수는 성장 표현이며 별도 수집·해금이나 개별 공격 능력을 뜻하지 않는다.

자동 진행을 기본으로 하고 드래그는 선택이다. 마녀가 적에게 피해를 받는 구조는 이번 전투에 없으며, 위치 조절은 전투를 유지한 채 마녀를 움직여 보는 개입이다. 이동을 요구하는 회피 게임으로 바꾸지 않는다. 제한시간 보스는 성장의 목적과 재도전의 이유를 제공한다. ‘별비’는 돌파를 돕지만 무스킬 강화 경로도 열어 둔다.

사람 플레이에서는 첫 강화 전후 화력 차이를 알아차리는지, 발사→피해→정화→보상을 따라갈 수 있는지, 드래그 없이 진행해도 답답하지 않은지, 보스 실패 뒤 강화/재도전 이유가 읽히는지 확인한다. 재미·새로움·귀여움에 대한 사람 판정은 **NOT_MEASURED**다. 봇 승리나 캡처만으로 이를 PASS로 바꾸지 않는다.

## 전투와 경제

| 항목 | 첫 플레이 임시 수치 |
|---|---|
| 내부 시간 | delta 누적, 고정 1/120초 단위; 프레임 수와 분리 |
| 자동 이동 | 중심 x=270, 좌우 진폭 93, 초당 최대 65 이동 |
| 선택 드래그 | x=65~475, y=490~660, 초당 520 이동; 해제 후 2초 유지 |
| 일반 적 | HP = 18 + floor(현재 정화 수 / 4) × 4, 최대 4마리 |
| 일반 적 생성 | 시작 즉시; 이후 1.8초 간격, 숲 12마리 정화 시 보스 |
| 공격력 | 6 × 1.5^공격 단계 |
| 사격 간격 | max(0.18, 1.05 / 1.22^속도 단계)초 |
| 발사체 | 가장 가까운 적 추적, 초당 620 이동, 수명 2초 |
| 일반 적 보상 | 별빛 8 + 획득 단계 × 3, 정화잎 1 |
| 강화 가격 | ceil(기본 가격 × 1.65^현재 단계), 기본 공격 12/속도 18/획득 14 |
| 외형 성장 | 공격 +0~1 지팡이/작은 탄, +2~3 마법포, +4 이상 거대 마도구/큰 탄/정령 3마리 |
| 가시왕 | HP 720, 제한시간 24초 |
| 수동 별비 | 210 + 현재 공격력 × 5 피해, 즉시 적중, 쿨다운 8초 |
| 보스 보상 | 현재 일반 적 별빛의 8배, 정화잎 5 |
| 패배/승리 뒤 | 전투 정화 수 초기화, 별빛·정화잎·강화 보존, 다시 숲 진행 |

자동 검사의 자연 보상 경로는 공격 +4까지 우선 구매하고 속도 +3까지 구매를 시도하며 패배하면 재도전한다. 재화·피해를 주입하지 않고 400 시뮬레이션 초 안에 무드래그·무스킬 승리를 확인한다. 경계 검사와 성장 캡처의 1,000 별빛 fixture는 이 자연 보상 경로와 분리한다. 무강화 경로는 보스 제한시간 패배를 확인한다.

## 구조와 입력

`game/main.tscn`의 Control 하나가 `battle.gd` 전투 상태·절차적 렌더링·UI를 소유한다. FOREST→BOSS→LOST/WON→FOREST 상태를 명시하고 종료 상태에서는 사격·보상·스킬을 멈춘다. `sound.gd`는 런타임 PCM 효과음과 6개 재생 채널을 소유한다. 외부 음원과 네트워크는 사용하지 않는다.

540×960 세로 기준 canvas_items 확장 레이아웃이다. 상단 상태·중앙 전투·하단 작업대를 분리하고 넓은 화면에서는 콘텐츠 폭을 600으로 제한해 중앙 정렬한다. 전투 좌표를 화면 폭·전투 높이에 매핑한다. 장식 Label/진행바는 입력을 통과하고 버튼만 입력을 소비한다. `_unhandled_input`은 남은 전투 입력만 받으며 UI 위 해제·포커스 상실에서도 드래그를 종료한다. 모바일 GUI 버튼을 위해 터치의 마우스 변환을 켠다. 시스템 한국어 폰트 목록과 시스템 fallback을 사용하며 실제 기기 폰트 구성에 따른 검증은 후속이다.

## 검사 경계와 후속

`tests/run.py`는 엔진 버전, 임포트 로그와 종료 코드, 실제 씬을 통한 제품 assert를 확인한다. `--capture`는 실제 디스플레이 렌더러에서 작은 마녀/성장/보스/스킬/승리/긴 화면/넓은 화면/패배를 저장한다. 캡처는 수치 fixture와 씬 입력으로 제어하며 OS 입력 검사가 아니다. 효과음은 캡처 중 Dummy 오디오로 실행하고 청취 PASS를 주장하지 않는다. 독립 리뷰는 구현 세션과 별도로 Controller가 수행한다.

직접 Godot 검사에서 격리 환경변수 누락으로 전투 검사를 시작하지 못했던 실패를 임시 사본에서 재현했다. 가드를 제거하는 대신 `smoke.gd`의 미설정 진입을 Python 격리 실행기로 연결했다. 최초 프로세스는 씬 로드·진행 파일 접근 없이 자식 검사 결과를 반환하고, 이미 지정된 격리 경로가 실제 `user://`와 다르면 계속 실패한다. `tests/test_entrypoints.py`는 실제 Godot으로 직접 진입 성공, 잘못된 격리 경로 거부, 의도한 제품 assert 실패 전파, 임포트 로그 오류 전파를 검사한다. 최초 프로세스도 임시 사용자 경로에서 실행하고 기존 파일 보존·검사 표식 미생성을 확인한다. 사용하지 않는 스크립트는 임포트 때 파싱되지 않을 수 있어 오류 fixture는 실제 오토로드에 연결한다.

후속은 로컬 저장·버전·진행 소유권, 시계 역행/중복 지급 방지를 포함한 최대 24시간 오프라인 보상, 재화 뽑기/제작/동급 합성, 정령 해금과 첫 환생이다. IdP 로그인·기기 간 공유·기존 로컬 진행 이전은 필수 후속 요구다. 출시·결제·새 서비스는 이 작업에 포함하지 않는다.

2026-11-06 이번 재검사에서 Godot 4.7.2 임포트 로그 오류 0건, 제품 assert 52개와 진입 경로 회귀 4개 통과를 확인했다. 자연 보상 경로의 무스킬 승리는 약 87.9 시뮬레이션 초, 공격 +4/속도 +2였다. 이전 구현 세션의 실제 GUI 캡처는 macOS 서비스 연결 오류 뒤 90초 타임아웃으로 실패해 이미지가 생성되지 않았다. 이번 수정은 검사 진입 경로에 한정했으며 GUI 캡처를 재실행하지 않았다. 실제 GUI 실행·시각 판독·OS 입력·음향 청취·사람 재미·모바일 실기기는 모두 **NOT_MEASURED**로 남긴다. 생성된 소스를 독립 수용·출시·기기 실행 PASS로 표시하지 않는다.
